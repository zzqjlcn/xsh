# xsh

同时提供终端界面和内置浏览器工作区的 SSH 管理工具。通过一个可执行文件管理主机、使用多选项卡和分屏终端，并传输文件。

[English](README.md) · **简体中文**

## 功能

- **主机管理**：搜索、标签、最近连接排序，支持密码、私钥认证及单跳跳板主机。
- **浏览器工作区**：多选项卡、可嵌套的垂直/水平分屏、右键菜单，以及各分屏独立的关闭按钮。
- **独立账号**：每个账号维护自己的主机和加密凭据，由管理员管理用户，支持向多个账号分享配置。
- **文件传输**：浏览器提供 SFTP 浏览、上传和下载；命令行支持本地与远程之间的递归复制。
- **密码工具**：测试 SSH 密码认证、修改远程 Linux 用户密码、生成和复制随机密码。
- **本地存储**：主机、历史、账号及加密凭据使用 SQLite，无需单独部署数据库或安装前端。

## 快速开始

在项目目录中使用 **Go 1.23.4 或更高版本**构建：

```sh
go build -o xsh ./cmd/xsh
./xsh web
```

Windows：

```powershell
go build -o xsh.exe ./cmd/xsh
.\xsh.exe web
```

打开终端打印的地址，默认是 `http://127.0.0.1:8080/`。首次运行时：

1. 复制终端打印的管理员初始化码。
2. 在浏览器中输入初始化码，创建首个账号，该账号自动成为管理员。
3. 添加主机并连接；在**设置 → 用户管理**中创建其他账号。

不提供公开注册入口。初始化码也保存在配置目录中的 `web-setup-code` 文件中。

不带子命令运行 `./xsh` 可打开终端界面。开发时也可直接运行 `go run ./cmd/xsh` 或 `go run ./cmd/xsh web`。下文命令示例假设已将 `xsh` 加入 `PATH`。

## 浏览器工作区

### 主机与连接

点击工具栏的主机列表图标，可新增、搜索、编辑和连接主机。各账号的主机列表相互独立，主机别名可以跨账号重复；编辑已有主机时，别名为只读。

- **认证**：可保存密码，或在编辑器中粘贴私钥内容。浏览器模式不接受服务端私钥文件路径。
- **跳板主机**：从自己的主机列表中选择，支持搜索和单跳转发。
- **测试密码**：点击主机密码输入框内的插头勾选图标，验证当前地址、端口、用户名和所选跳板；不保存表单，也不打开终端。编辑时密码留空会使用已保存密码。测试仅使用密码认证，超时为 15 秒。
- **临时 SSH 用户**：连接弹窗默认填入主机配置中的用户名，可修改为其他用户并输入本次连接的密码。不会复用原用户的已保存密码或私钥，也不会修改主机配置。

首次连接服务器需要确认指纹，已知密钥发生变化时拒绝连接。密码测试对新指纹的信任仅用于本次测试；正常终端连接会保存已确认的密钥。

### 选项卡与分屏

点击选项卡右侧的 **+** 打开主页，已有连接继续保留。右键选项卡可选择**新建、复制、关闭、关闭其他、关闭所有、垂直分割、水平分割**。

垂直分割为左右并排，水平分割为上下排列，支持嵌套。复制和分割会为当前终端的用户建立新的 SSH 连接；临时用户需重新输入密码。也可右键具体的终端区域，对该终端进行分割。

每个分屏右上角都有关闭按钮，只关闭对应终端，剩余区域自动填满空间；关闭选项卡则会断开其中的全部终端。

终端区域的右键菜单提供**复制、粘贴、全选、清屏、分屏、关闭当前终端**。清屏只清理本地终端显示，不向远程 shell 发送命令。文件传输、修改远程密码跟随当前聚焦的终端。剪贴板访问受浏览器和部署环境影响，无法读取剪贴板时可使用键盘粘贴。

终端支持 ANSI 16 色、256 色、真彩色、`xterm-256color` PTY 和窗口尺寸同步；服务器允许时，还会设置 `COLORTERM=truecolor`。

### 账号、分享与锁屏

设置中包含**我的账号、外观**，管理员还可使用**用户管理**，创建、启用或停用普通账号。登录页会在当前浏览器中记住最近一次成功登录的用户名，不保存登录密码。

分享主机时，在编辑器中点击**分享配置**，搜索并勾选一个或多个接收账号。接收者打开分享收件箱，点击**添加**，填写自己的 SSH 用户名和凭据后保存。

| 分享内容 | 不分享的内容 |
| --- | --- |
| 名称、地址、端口、标签 | SSH 用户名、密码、私钥及路径、认证设置、跳板引用、密码保存标记、登录历史 |

接收后形成独立副本，发送方后续编辑或删除不会影响接收方。别名重复时需改名后导入，导入失败不会消耗待接收的分享。分享配置不会授予访问发送方凭据或会话的权限。

**锁屏**隐藏工作区，输入当前账号密码后恢复；保留已有 SSH 连接、终端缓冲和传输任务。锁屏期间禁止终端输入和新的接口操作，远程输出继续更新。**退出登录**关闭当前登录会话的连接。刷新或关闭浏览器页面会断开其中的终端，锁屏状态下也一样。

登录会话最长持续 12 小时，xsh 重启后失效。修改账号密码或停用账号会使该用户的所有会话失效；修改登录密码会保留已保存的凭据。目前不提供管理员重置密码或账号加密密钥恢复功能。

### 文件传输

连接后点击文件传输图标，通过当前聚焦终端的已有 SSH 连接浏览远程目录。支持双击文件夹、输入路径、返回上级和刷新。

可通过文件选择器上传多个文件，也可拖入当前目录或指定文件夹行。传输显示进度并支持取消，远程同名文件会被拒绝覆盖。下载交给浏览器下载管理器处理。浏览器暂不支持递归上传或下载文件夹，递归复制可使用命令行。

### 修改远程密码

在已连接终端的工具栏中点击钥匙图标，修改**当前实际登录的远程用户**的系统密码。这不会修改 xsh 账号密码或命令行密码本的主密码。

当前密码可使用匹配主机和 SSH 用户的已保存密码，也可手动输入。眼睛和复制图标可按需读取、显示或复制已保存密码。仅使用私钥登录时，可能仍需填写当前系统密码；服务器允许时，root 可留空。

新密码至少八个字符，并需满足远程服务器的密码策略。输入框中提供显示、复制和随机生成按钮；随机密码固定为 20 位，包含大小写字母、数字和符号，生成时自动填写确认密码。

操作通过独立 SSH PTY 执行 `LC_ALL=C passwd`，超时为 30 秒。支持标准英文 Linux 提示，不支持自定义 PAM/OTP 提示、网络设备或 Windows 服务器。密码通过 SSH 输入传递，不放入命令参数。

成功后，仅更新当前账号中主机和 SSH 用户均匹配的已有保存密码。临时凭据不会保存，其他账号和命令行凭据不受影响，当前终端继续保持连接。关闭弹窗前请复制新密码。超时或断线导致结果不明确时，应先验证远程密码再重试；弹窗会阻止立即重复提交。

## 终端界面与文件复制命令

运行 `xsh` 打开终端主机列表：

| 按键 | 操作 |
| --- | --- |
| `↑` / `↓`、`j` / `k` | 移动选择 |
| `Enter` | 连接 |
| `a` / `e` / `d` | 新增 / 编辑 / 删除主机 |
| `/` | 搜索 |
| `s` | 按名称 / 最近登录排序 |
| `cp` | 打开文件复制向导 |
| `q` | 退出 |

复制向导支持本地与远程之间、两台远程主机之间的复制。路径输入时按 `Tab` 补全，重复按键可循环候选。传输显示字节和文件进度，可用 `Esc` 或 `q` 取消，并保留最近十次成功传输记录。目录递归复制，确认后可覆盖目标文件；符号链接和特殊文件会被拒绝。

命令模式中，本地使用普通路径，已保存的命令行主机使用 `别名:/路径`：

```sh
xsh cp ./release.tar.gz dev:/tmp/release.tar.gz
xsh cp dev:/var/log/app.log ./app.log
xsh cp dev:/tmp/data backup:/srv/data
```

若本地路径可能被误认为远程地址，可加上 `local:` 前缀。命令模式不打开全屏界面，但认证和新主机密钥确认仍可能需要交互。

在当前 shell 中启用主机别名补全；将对应命令加入 shell 配置文件可长期启用：

```bash
# Bash
source <(xsh completion bash)
# Zsh
source <(xsh completion zsh)
```

```powershell
xsh completion powershell | Out-String | Invoke-Expression
```

## 数据与凭据

| 平台 | 默认数据库路径 |
| --- | --- |
| Windows | `%AppData%\xsh\xsh.db` |
| Linux | `~/.config/xsh/xsh.db`，或 `$XDG_CONFIG_HOME/xsh/xsh.db` |
| macOS | `~/Library/Application Support/xsh/xsh.db` |

设置 `XSH_CONFIG_HOME` 可覆盖配置目录。命令行主机、历史和密码本，与浏览器账号、主机和分享记录使用同一 SQLite 数据库中的不同表。命令行密码本通过主密码使用 Argon2id 和 AES-256-GCM 加密。浏览器账号各自拥有随机加密密钥，由登录密码派生的密钥封装；SSH 密码和私钥加密保存。主机配置元数据不加密。

首次初始化时，旧的 `hosts.json`、`copy-history.json` 和加密的 `secrets.db` 会在同一事务中自动导入，原文件保留为备份。旧系统钥匙串中的凭据仍可读取，并可在命令行密码本解锁后复制到其中；新保存使用 SQLite，密码本条目优先于旧钥匙串条目。

创建管理员时，可选择将已有命令行主机列表复制到首个账号。导入加密凭据需要原命令行主密码，导入后按该账号重新加密；命令行数据和主密码流程保持不变。其他账号从空列表开始。

浏览器主机密钥记录保存在配置目录中的 `web-known-hosts/<用户 ID>`；命令行使用 `~/.ssh/known_hosts`。

备份前停止 xsh，并备份配置目录。请另外妥善保存命令行主密码和账号密码：仅有数据库备份、没有对应密码，无法恢复加密凭据。能够访问数据库和进程内存的本机用户属于部署信任范围。

## 网络部署

```sh
xsh web --port 9090
xsh web --port 0
xsh web --host 0.0.0.0 --port 8080 --root-path /xsh
```

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `--host` | `127.0.0.1` | 监听地址，`0.0.0.0` 允许其他机器连接 |
| `--port` | `8080` | 监听端口，`0` 自动选择可用端口 |
| `--root-path` | `/` | 挂载路径，支持 `/tools/xsh` 等多级路径 |

通过网络访问时，使用可信反向代理提供 HTTPS。以 `/xsh` 为例，在已有 Nginx server 中加入：

```nginx
location = /xsh {
    return 308 /xsh/$is_args$args;
}

location /xsh/ {
    proxy_pass http://127.0.0.1:8080;
    proxy_http_version 1.1;
    proxy_set_header Host $http_host;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_read_timeout 3600s;
    proxy_buffering off;
}
```

`proxy_pass` 不要添加末尾斜杠，以保留路径前缀；保留浏览器的 `Origin` 请求头。静态资源、接口、WebSocket 和 Cookie 路径均跟随 `--root-path`。仅希望通过反向代理访问时，应限制对上游端口的直接访问。大文件上传需按需设置 Nginx 的 `client_max_body_size`。

浏览器连接需要当前登录会话及其令牌，终端和传输连接绑定到创建它的登录会话。账号隔离不限制远程用户本身的操作系统权限；目前未实现目标 IP 白名单。
